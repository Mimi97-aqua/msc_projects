# Housing in Berlin
This project entailed conducting exploratory data analysis using only Python on a dataset containing data on housing in Berlin from 1900 to 2015.

## About Files
- `analysis.ipynb`: contains code for the analysis
- `brief.txt`: contains problem statement
- `report.pdf`: official report documenting entire analysis

## Project Setup
### 1. Local setup
Python 3.10+ required
- Clone this repository using `git clone <repo_url>`
- `cd` into `msc_projects/com7024`
- Setup and activate virtual environment:
```shell
python3 -m venv .venv/
source .venv/bin/activate
```
- Install requirements: `pip install -r requirements.txt`

### 2. Running Online
- Download the dataset and notebook from this folder
- Upload them to your preferred Jupyter Notebook instance like Google Colab
