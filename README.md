## MSc. Projects
This repo contains the list of projects completed during my Data Science Master's program at [Arden University](https://arden.ac.uk/).

## Courses and Project Brief
### Semester 1
- [COM7023 (Mathematics for Data Science)](https://github.com/Mimi97-aqua/msc_projects/tree/main/com7023): Performing mathematical investigations at Urban Resource Intelligence (a consultancy that advises local authorities on improving urban resource systems) as part of my induction to demonstrate my ability to perform advanced mathematical techniques to a real-world data analytics problem assigned by my line manager.
- [COM7024 (Programming for Data Analytics)](https://github.com/Mimi97-aqua/msc_projects/tree/main/com7024): Performing EDA on a dataset containing data on residential property information in Berlin with the aim of using basic analytics to help predict possible housing market trends in the future within Berlin. This project assumes the role of a junior data analyst at a German real estate company.
