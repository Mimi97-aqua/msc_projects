# Urban Resource Systems
This project entails performing investigations using advanced mathematical techniques on a range of data analytics 
problems present at URI (Urban Resource Intelligence) - a consultancy that advises local authorities on improving
urban resource systems.

### About Files
- `analysis.ipynb`: contains Python code with calculations and visualizations. Setup instructions are in the `Project Setup` section below.
- `brief.txt`: contains problem statement
- `report.pdf`: contains my report after investigation

### Project Setup

#### Option 1: Run Online
1. Download this repository and upload `msc_projects/com7023/analysis.ipynb` to your preferred Jupyter Notebook instance
like Google Colab.
2. Run the cells to see results.

#### Option 2: Run Locally
1. Clone this repository: `git clone <repo_url>`
2. `cd` into `msc_projects/com7023`
3. Set up and activate a virtual environment:
```shell
python3 -m venv .venv/
source .venv/bin/activate
```
5. Install requirements using `pip3 install -r requirements.txt`
6. Run the file `analysis.ipynb` to see results.
