# COM7022 Assignment Brief

## Task Summary

The assignment is given as two tasks. All the tasks are to be completed individually.

- **Task 1 (Practical Project)** will evaluate your practical understanding of Machine Learning methodologies for critical analysis, through a real-world Machine Learning project written in Python.
- **Task 2 (Critical Report)** is designed to give you the opportunity to demonstrate your Machine Learning critical reporting skills, comprehensively written in an easily understandable manner, based on your investigation.

A clear, concise analysis for all Tasks is to be given within the submission, complemented with screenshot evidence of all processes and results. You are to submit a single Word or PDF document for all tasks, and your code for Task 1 is to be included within an appendix, so that it can be checked and verified it is working correctly. Your student ID number must be clearly displayed in the uploaded file.

## Task 1: Practical Project

You have recently joined a rapidly growing e-commerce company as a Machine Learning Analyst. The company maintains a large dataset containing product information, pricing details, availability status, sales records, update history, and item locations. Your first task is to develop clustering models using the dataset **Sales-[5444].csv** to group products based on their characteristics and sales performance.

You are required to:

- Prepare the dataset to support effective machine learning analysis.
- Select and justify appropriate features for inclusion within the analysis.
- Apply multiple clustering techniques (e.g., K-Means, Hierarchical Clustering, and DBSCAN) to the dataset.
- Evaluate the suitability of the selected machine learning methods for the problem context.
- Apply data transformation techniques, including scaling, normalisation, and the treatment of categorical variables, where appropriate.
- Use dimensionality reduction techniques (e.g., Principal Component Analysis (PCA)) to support analysis and visualisation where appropriate.
- Evaluate and compare clustering models using appropriate performance and validation measures.
- Justify the selection of the most suitable model based on technical and business considerations.
- Analyse and describe the characteristics of the resulting clusters and their relevance to the business scenario.

This task will provide the analytical foundation for the executive report presented in Task 2, where findings and recommendations will be communicated to a professional audience.

## Task 2: Critical Report

Drawing on the machine learning analysis undertaken in Task 1, prepare a professional report for an executive audience. The report should:

- Evaluate the suitability of the machine learning methods used to address the business problem, including consideration of feature selection and model development decisions.
- Compare the performance and effectiveness of the machine learning models applied, critically evaluating their strengths, limitations, and suitability for the given scenario.
- Justify the selection of the final model using both technical and business considerations.
- Present the outcomes in a clear and accessible manner for non-technical stakeholders and include appropriate visualisations, interpretation of key findings, and evidence-based recommendations that support strategic decision-making.
